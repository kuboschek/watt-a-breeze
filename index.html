Adaptive cooling

Browser mode

Connect a heart-rate sensor and/or cycling-power sensor. The browser requests the higher airflow once a second using your thresholds below.

Ready when you are—

Uses standard BLE heart-rate and cycling-power services; ANT+ and FTMS-only trainers are unsupported. Keep this page visible and your computer awake. If all enabled readings become stale for 10 seconds, control pauses and the last fan setting remains.

Cooling profile

Choose thresholds and preview how sensor requests combine. Settings save in this browser. Sample values are starting points for testing, not personalized recommendations.

i
Native adaptive mode still needs the Wahoo app.

Firmware 2.0.43+ supports all five sensor types. This PoC cannot read or write native pairing or thresholds. Heart rate and power settings below drive browser mode; the other three are planning and preview only. The preview uses a linear curve; Wahoo’s exact curve is unverified.
